# PIC-Based Pulse Oximeter Prototype (2025)

Academic electronics project to design and test a pulse-oximeter prototype. The setup uses a PIC18F4321 microcontroller, a MAX30102 optical sensor for red/infrared photoplethysmography, I²C for sensor communication, and UART via a CP2102 converter to display measurements on a computer.

## Contents
- `report/`: Original academic project report (with team credits).
- `images/`: Original photograph of the prototype selected for the portfolio.

## Technologies
PIC18F4321 · MAX30102 · C / MPLAB X IDE · I²C · UART · CP2102.

## Status and limitations
The report documents a functioning educational prototype and basic heart-rate / SpO₂ readouts, but **no validation against a certified clinical pulse oximeter** was performed. Results should not be used for medical decisions. The original firmware/source code has not been supplied for this repository and is **not claimed to be available**.
